================================================================================
                              PROJECT OVERVIEW
================================================================================

This is an Asset Register application built on Cloudflare Workers with a React
frontend. It provides a web interface for managing and tracking assets through
a RESTful API.

Tech Stack:
- Backend: Cloudflare Workers (TypeScript)
- Frontend: React with React Router
- Build Tool: Vite
- Database: SQLite (via Cloudflare D1)
- Configuration: wrangler.json, tsconfig files

================================================================================
                       CLOUDFLARE CONFIGURATION
================================================================================

The application uses Cloudflare Workers and D1 database. Configuration is in
wrangler.json. Key settings include:

- Main worker: workers/app.ts
- Database: D1 database for persistence
- Assets: Static asset serving

To set up a new environment:
1. Update wrangler.json with your Cloudflare account details
2. Create D1 database: npx wrangler d1 create asset-register
3. Update wrangler.json with the database ID
4. Apply migrations: npx wrangler d1 migrations apply asset-register
5. Deploy: npx wrangler deploy

================================================================================
                          API DOCUMENTATION
================================================================================

The API routes are defined in app/routes/api.registers.ts. Key endpoints:

GET  /api/registers      - List all registers
POST /api/registers      - Create a new register
GET  /api/registers/:id  - Get specific register
PUT  /api/registers/:id  - Update register
DELETE /api/registers/:id - Delete register

Check app/routes/api.registers.ts for complete API documentation.
